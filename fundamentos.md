# Banco Relacionais

Bancos de dados Realcionais possuem esse nome por causa da possibilidade de criar relações entre tabelas existentes.

## Registros e Atributos

-   Registros são as linhas.
-   Atributos são as colunas.

## Tabelas em Bancos de Dados

Tabelas diferentes em bancos de dados costumam conter listas de entidades diferentes.

## Chaves e Valores Únicos

### Chave Primária - Sintética ou Substituta

Normalmente nomeadas como "id" e não pode ser repetidas.

### Chaves Estrangeiras

São chaves que fazem referências a registros de outras tabelas.

### Chaves Compostas

Chaves compostas são chaves obtidas de combinações de atributos.

## Tipos de Relacionamentos

-   Um-para-muitos (one-to-many) - Mais utilizado.
-   Muitos-para-muitos (many-to-many).
-   Um-para-um (one-to-one) - Útil para dados de acesso.
