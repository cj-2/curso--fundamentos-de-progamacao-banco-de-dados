# Banco de Dados

## O que resolvem?

Banco de dados resolvem problemas relacionados aos seguintes tópicos:

-   Tamanho
-   Atualização
-   Precisão
-   Segurança
-   Redundância
-   Importância ou Valor

## SGDB ou DBMS

Sistema de Gerenciamento de Banco de Dados.

## Modelos

-   Plano (ou tabular)
-   em Rede
-   Hierárquico
-   Relacional: RDBMS (Mais comum)
-   Orientado a Objetos
-   NoSQL
-   ...

### Tipos

-   Graph - Neo4j
-   Object - Realm, Objectivity/DB
-   Document CouchDB, MongoDB...

### Exemplos

-   MySQL
-   SQL Server
-   Microsoft Access
